# Destrava+

Plataforma para criar um plano de desenvolvimento profissional.

## O problema
Muitos jovens sabem que querem construir uma carreira, mas não sabem por onde começar. Falta orientação para identificar as habilidades necessárias, organizar os estudos e transformar um objetivo profissional em um plano de ação.

## ODS
- ODS 4: Educação de qualidade (principal)
- ODS 8: Incentivo e preparação para o mercado de trabalho

## Tecnologias
HTML, CSS, JavaScript e localStorage

## Como rodar
1. Baixe ou clone o repositório
2. Inicie um servidor local na pasta do projeto (por exemplo, com a extensão Live Server do VS Code)
3. Abra `index-lc.html` pelo endereço local

O cadastro, as sessões e as atividades ficam salvos neste navegador. As senhas são armazenadas com hash e salt, mas a autenticação é apenas demonstrativa e não substitui um backend para uso em produção.
